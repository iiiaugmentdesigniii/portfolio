QA & AccessibilityV2

I test websites for functionality, responsive behavior, accessibility and visual consistency, then document findings for review and retesting.

Process

Testing Process

01

Review

Review the website, requirements and expected behavior before beginning testing.

02

Plan

Identify test scenarios and create test cases or checklists for important functionality.

03

Test

Test functionality, responsive behavior, navigation, forms and browser behavior.

04

Accessibility

Evaluate keyboard access, focus behavior, structure, contrast and other WCAG-related requirements.

05

Document

Record defects with reproduction steps, expected results, actual results and supporting evidence.

06

Retest

Verify fixes and perform regression checks when changes could affect existing functionality.
